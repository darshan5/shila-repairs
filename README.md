# Shila Repairs

Maintenance management app for Shila LLC. Syncs work orders from WalkTheFloor.

## Features

- Work order sync from WalkTheFloor via API
- Extended status management (pending, approved, in progress, deferred, completed, invoiced)
- Invoice creation from completed work orders
- Independent task management
- Status pushback to WalkTheFloor

## Stack

- Next.js 16 + TypeScript
- Prisma + PostgreSQL
- NextAuth v5 (JWT)
- Tailwind CSS
- Deployed on Dokploy
